PLAYPIX Streaming

A Netflix-inspired video streaming platform with user authentication and media library management

Laravel MySQL Tailwind CSS JavaScript

Project Overview

PLAYPIX is a video streaming web application built with Laravel that brings a Netflix-like experience to browsing and watching content. It covers the full journey of a media platform — from discovering titles in a gallery to streaming them in a dedicated player.

The system includes user authentication, a media library, cast profiles, and a complete admin panel for managing videos and cast members. It’s designed to make both viewers and content managers feel right at home.

Key Features

  • User authentication and account management
  • Media library and browsing gallery
  • Dedicated video streaming player
  • Cast profiles and cast management
  • Admin panel for media and content management

Impact

This project put the full streaming stack into practice — from setting up authentication and media workflows to building an intuitive admin interface. It strengthened my skills in Laravel development, database design, and crafting user-friendly interfaces for both clients and administrators.
